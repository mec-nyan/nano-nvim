# Nano-nvim

Another nvim configuration :cherry_blossom:

This tries to be a _fast setup_ and minimal config with just the needed plugins. But making sure
you can get up to speed very quickly.

This means to use as little as possible to get these things working:

- LSP
- Completion
- Keybindings
- Colorscheme
- Debugger

Optional:

- Status line
- File browser (netrw is really cool actually!)
- Finder (i.e. Telescope) (first try native grep)
