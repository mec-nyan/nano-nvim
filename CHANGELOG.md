# Changelog

This is a personal project, and maybe with time other people can benefit from it.

I didn't keep a changelog at the beginning because it was a very basic configuration.
These are the configurations that I actually use for work, so, I've started to add several
more plugins than I originally thought... See the project README for details.

Now that I'm making a lot of changes, I'll keep versions and a Changelog just in case someone
(and that someone may be the future-me) want to use a specific version of the repo that uses
a particular plugin or configuration instead.
